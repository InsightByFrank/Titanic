## 📖 Description  
This Excel-based dashboard delivers actionable business and demographic insights from historical Titanic passenger data. Using Power Pivot, Power Query (ELT), DAX, and interactive Excel dashboards, it analyzes survival rates by age, class, and gender while forecasting the profitability of launching a modernized Titanic-style voyage.

The dashboard serves as both a historical analysis and a future-facing business model, guiding stakeholders through strategic segmentation, pricing, and risk mitigation.

## ⚙️ Excel Tools & Features  
- **Power Pivot** – Data modeling across survival, pricing, age, gender, and class  
- **Power Query (ELT)** – Cleaned and transformed Titanic CSV data  
- **DAX Measures** – Revenue per passenger, survival rates, ticket value analysis  
- **Pivot Tables & Charts** – Dynamic summaries by class, cabin, gender, siblings  
- **Conditional Formatting** – Visual alerts for high-risk zones (e.g., third-class cabins)  
- **Interactive Slicers** – For filtering passenger type, class, gender, age group

## 📌 Insights & Recommendations

- **Gender-Based Survival**:  
  - Females had a 74% survival rate vs. 19% for males.  
  - 📌 *Target female safety-conscious audiences in future travel planning.*

- **Age-Based Trends**:  
  - Infants had high survival; adults experienced highest deaths.  
  - 📌 *Design critical care plans prioritizing infants and solo adults.*

- **Revenue Drivers**:  
  - Adults generated $21K+ of total revenue.  
  - 📌 *Tailor premium offerings toward adult travelers.*

- **Class Disparities**:  
  - Third class had 41.75% death rate; first class had better outcomes.  
  - 📌 *Use this for risk tier modeling in cruise/hospitality planning.*

- **Spending by Gender**:  
  - Males: $14.7K revenue | Females: $14K  
  - 📌 *Design bundled offers by gender-based travel intent.*

- **Solo Travelers**:  
  - Highest death rate linked to passengers without companions.  
  - 📌 *Bundle packages for families or loyalty groups to boost safety perception.*
